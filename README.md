## 프로젝트 소개

부경대학교 데이터 사이언스 수업에서 타이타닉 승객의 생존 여부를 예측했습니다. 생존 여부가 기록된 승객 891명을 집단별로 비교하고, 이름에서 호칭을 뽑고 가족 관계에서 동승 형태를 계산해 피처를 구성했습니다. 다섯 분류 모델을 비교한 뒤 랜덤 포레스트로 테스트 승객 418명의 생존 여부를 예측했습니다. [Kaggle 데이터](https://www.kaggle.com/competitions/titanic/data) · [Jupyter 노트북](Notebook/titanic.ipynb)

## 데이터 전처리

학습 데이터에서 나이 177건과 탑승항 2건이 비어 있었습니다. 나이는 학습·테스트 데이터 각각의 중앙값으로, 탑승항은 학습 데이터의 최빈값으로 채웠습니다. 테스트 데이터의 요금 결측 1건에는 테스트 요금의 중앙값을 사용했습니다. 객실 번호 `Cabin`은 학습 데이터 891건 중 687건이 비어 있어 제외했습니다.

## 승객 집단별 생존율

생존 여부와 객실 등급 `Pclass`의 상관계수는 −0.34, 요금과의 상관계수는 0.26이었습니다. 1등석을 가장 작은 숫자로 기록하므로, 이 수치는 높은 등급에 탔거나 높은 요금을 낸 승객의 생존율이 높았던 경향을 보여줍니다.

승객을 등급별로 나누면 생존율은 1등석 63.0%, 2등석 47.3%, 3등석 24.2%였습니다. 여성 승객의 생존율은 74.2%, 남성 승객은 18.9%였습니다. 아래 그래프는 탑승항과 등급을 같게 맞춰도 모든 조합에서 여성 승객의 생존율이 높았음을 보여줍니다. 모델 입력에 객실 등급, 성별, 탑승항을 포함했습니다.

## 주요 피처와 설계 과정

**호칭.** 이름에서 정규식으로 호칭을 뽑아 `Title`을 만들었습니다. 남성 승객 중에서도 어린 남성에게 주로 쓰인 `Master`의 생존율은 57.5%, `Mr`는 15.7%였습니다. 호칭을 이용하면 성별이 같은 승객을 더 세분할 수 있습니다. `Mlle`과 `Ms`는 `Miss`로, `Mme`는 `Mrs`로 합쳤고 드문 호칭은 `Rare`로 묶었습니다.

```python
df['Title'] = df['Name'].str.extract(' ([A-Za-z]+)\.', expand=False)
df['Title'] = df['Title'].replace(['Lady', 'Countess', 'Capt', 'Col', 'Don', 'Dr', 'Major', 'Rev', 'Sir', 'Jonkheer', 'Dona'], 'Rare')
df['Title'] = df['Title'].replace(['Mlle', 'Ms'], 'Miss')
```

**가족 규모와 단독 탑승.** 형제자매·배우자 동승 인원 `SibSp`가 0명, 1명, 3명인 집단의 생존율은 각각 34.5%, 53.6%, 25.0%였습니다. `SibSp`가 0이어도 부모나 자녀와 함께 탔을 수 있으므로, 부모·자녀 수 `Parch`와 본인까지 더해 `FamilySize`를 계산했습니다. 가족 규모가 1인 경우 `IsAlone`을 1로 표시했습니다.

**나이와 요금 구간.** 나이는 같은 폭의 다섯 구간으로, 요금은 사분위수를 기준으로 네 구간으로 나눴습니다. 노트북은 학습·테스트 데이터에서 경계를 따로 계산하므로 같은 구간 번호가 서로 다른 범위를 뜻할 수 있습니다.

최종 입력은 객실 등급, 성별, 탑승항, 호칭, 가족 규모, 단독 탑승 여부, 나이 구간, 요금 구간 등 8개입니다. 성별과 탑승항은 숫자 코드로 변환했습니다.

## 사용한 모델과 성능

같은 승객 891명의 피처로 scikit-learn 분류 모델 다섯 개를 학습했습니다. 표의 정확도는 모델이 학습에 사용한 승객의 생존 여부를 맞힌 비율입니다.

| 모델 | 학습 정확도 |
| --- | ---: |
| 결정 트리 | 88.66% |
| 랜덤 포레스트 (트리 100개) | 88.66% |
| K-최근접 이웃 (k = 3) | 85.19% |
| 로지스틱 회귀 | 81.03% |
| 가우시안 나이브 베이즈 | 80.13% |

결정 트리와 랜덤 포레스트의 학습 정확도가 88.66%로 가장 높았습니다. 최종 제출 파일은 랜덤 포레스트로 예측한 테스트 승객 418명의 `Survived`를 `PassengerId`와 짝지어 생성했습니다.

새로운 승객에 대한 성능은 층화 K겹 교차 검증으로 추정할 수 있습니다. 각 학습 폴드에서 정한 결측치 대체값과 구간 경계를 검증 폴드에 그대로 적용하고, 같은 분할에서 호칭과 가족 피처를 추가하기 전후의 정확도를 비교하면 이 피처들이 예측에 도움이 되는지 확인할 수 있습니다.
