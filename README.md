## 프로젝트 소개

부경대학교 데이터 사이언스 수업에서 [Kaggle Titanic 데이터](https://www.kaggle.com/competitions/titanic/data)를 이용해 승객의 생존 여부를 예측했습니다. 생존 여부가 기록된 승객 891명을 대상으로 객실 등급, 성별, 가족 동승 여부에 따라 생존율이 어떻게 달라지는지 살펴봤습니다. 승객 이름과 가족 관계처럼 그대로 모델에 넣기 어려운 정보는 호칭과 가족 규모로 변환했습니다. 이렇게 구성한 8개 피처로 다섯 분류 모델을 비교하고, 랜덤 포레스트로 테스트 승객 418명의 생존 여부를 예측했습니다. 전체 분석과 실행 결과는 [Jupyter 노트북](Notebook/titanic.ipynb)에서 볼 수 있습니다.

## 데이터 전처리

학습 데이터에서 나이를 알 수 없는 승객은 177명, 객실 번호를 알 수 없는 승객은 687명이었습니다. 나이는 학습·테스트 데이터 각각의 중앙값으로 채웠습니다. 객실 번호(`Cabin`)는 대부분 비어 있어 제외하고, 모든 승객에게 기록된 객실 등급(`Pclass`)은 유지했습니다. 학습 데이터에서 누락된 탑승항 2건은 가장 흔한 탑승항으로, 테스트 데이터에서 누락된 요금 1건은 테스트 데이터의 요금 중앙값으로 채웠습니다.

## 승객 집단별 생존율

먼저 숫자형 변수와 생존 여부의 상관관계를 확인했습니다. 생존 여부와 객실 등급의 상관계수는 −0.34, 요금과의 상관계수는 0.26이었습니다. 1등석이 가장 높은 등급이므로 두 수치는 같은 경향을 가리킵니다. 높은 등급에 탔거나 비싼 요금을 낸 승객 집단에서 생존율이 높았습니다.

![객실 등급, 요금 등 숫자형 변수와 생존 여부의 상관관계](Resources/01_CorrelationHeatmap.png)

차이의 크기를 확인하기 위해 승객을 집단별로 나눴습니다. 생존을 1, 사망을 0으로 기록했으므로 각 집단의 평균이 곧 생존율입니다. **1등석의 생존율은 63.0%, 2등석은 47.3%, 3등석은 24.2%**였습니다. 숫자형 변수의 상관관계에서 빠져 있던 성별로도 차이가 뚜렷했습니다. 여성 승객의 생존율은 74.2%, 남성 승객은 18.9%였습니다.

![탑승항별로 객실 등급과 성별을 나누어 비교한 생존율](Resources/04_EmbarkedPclassSex.png)

위 그래프에서 각 행은 탑승항, 가로축은 객실 등급, 두 선은 남녀 승객을 나타냅니다. 전체 평균에서 보인 성별 차이가 같은 항구에서 같은 등급에 탄 승객 사이에서도 나타나는지 살펴볼 수 있습니다.

나이는 생존자와 사망자를 객실 등급별로 나눠 분포를 비교했습니다. 아래 그림에서 특히 눈에 띄는 부분은 3등석 사망자의 28세 부근입니다. 나이 결측치를 학습 데이터 중앙값인 28세로 채웠기 때문에 이 막대에는 실제 나이가 기록된 승객과 나이를 알 수 없는 승객이 함께 들어 있습니다.

![객실 등급별 생존자와 사망자의 나이 분포](Resources/03_AgeByPclassSurvival.png)

## 주요 피처와 설계 과정

**승객 이름에서 호칭을 추출했습니다.** 이름 전체는 승객마다 달라도 `Mr`, `Mrs`, `Miss`, `Master` 같은 호칭은 여러 승객에게 반복됩니다. 정규식으로 호칭을 추출하고, `Mlle`과 `Ms`는 `Miss`로, `Mme`는 `Mrs`로 통합했습니다. 등장 횟수가 적은 호칭은 `Rare`로 묶었습니다. 실제로 호칭별 생존율을 계산하면 같은 남성 승객 중에서도 어린 남성에게 쓰인 `Master`는 57.5%, `Mr`는 15.7%였습니다. 이름에서 성별만으로는 구분하기 어려운 집단을 찾아낸 사례로, 이 정보를 `Title`에 담았습니다.

**두 가족 관계 열을 조합해 동승 형태를 표현했습니다.** 형제자매·배우자 수(`SibSp`)가 0명인 집단의 생존율은 34.5%, 1명인 집단은 53.6%였습니다. 다만 이 값이 0이어도 부모나 자녀와 함께 탔을 수 있습니다. 그래서 부모·자녀 수(`Parch`)까지 합하고 본인 한 명을 더해 가족 규모(`FamilySize`)를 계산했습니다. 가족 규모가 1이면 `IsAlone`을 1로 설정해, 기록상 가족 없이 탑승한 승객을 구분했습니다.

최종 입력은 **객실 등급, 성별, 탑승항, 호칭, 가족 규모, 단독 탑승 여부, 나이 구간, 요금 구간**입니다. 성별과 탑승항은 숫자 코드로 변환했습니다. 나이(`AgeBand`)는 값의 범위를 같은 폭으로 5등분했고, 요금(`FareBand`)은 각 구간의 승객 수가 비슷하도록 사분위수로 나눴습니다. 승객 ID는 제출 파일에서 예측값을 원래 승객과 연결하는 데 사용했습니다.

## 사용한 모델과 성능

동일한 891명의 8개 피처로 scikit-learn 분류 모델 다섯 개를 학습했습니다. 아래 수치는 노트북에 기록된 실행 결과로, **모델이 학습에 사용한 승객의 생존 여부를 맞힌 비율**입니다.

| 모델 | 학습 정확도 |
| --- | ---: |
| 결정 트리 | 88.66% |
| 랜덤 포레스트 (트리 100개) | 88.66% |
| K-최근접 이웃 (k = 3) | 85.19% |
| 로지스틱 회귀 | 81.03% |
| 가우시안 나이브 베이즈 | 80.13% |

결정 트리와 랜덤 포레스트가 88.66%로 공동 1위였습니다. 최종 예측에는 랜덤 포레스트를 사용했습니다. 테스트 승객 418명에게 같은 8개 피처를 구성해 생존 여부를 예측하고, 승객별 `PassengerId`와 예측한 `Survived`를 짝지어 `submission.csv`로 저장했습니다.

다음 실험에서는 생존자 비율을 유지하는 층화 K-겹 교차 검증으로 모델을 비교할 수 있습니다. 같은 검증 분할에서 호칭과 가족 피처를 추가하기 전후의 정확도를 비교하면, 이번 분석에서 관찰한 집단별 차이가 새로운 승객을 예측할 때도 도움이 되는지 확인할 수 있습니다.

## 실행

Python 3와 Jupyter 환경에 pandas, NumPy, Matplotlib, seaborn, scikit-learn을 설치합니다. Kaggle에서 받은 `train.csv`, `test.csv`, `gender_submission.csv`를 `Notebook` 폴더에 두고, 해당 폴더에서 [titanic.ipynb](Notebook/titanic.ipynb)를 열어 위에서부터 실행합니다. 마지막 예측 셀을 실행하면 같은 폴더에 `submission.csv`가 생성됩니다.
